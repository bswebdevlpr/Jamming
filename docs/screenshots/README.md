# Screenshots

Drop product screenshots here, then uncomment the gallery table in the root [README](../../README.md#-screenshots).

## Naming convention

Use lowercase names that match the gallery in the README:

| File | Screen |
| --- | --- |
| `home.png` | Home / session list |
| `about.png` | About |

## Tips

- Capture in a mobile viewport (~390px wide, portrait) for a consistent look.
- Prefer PNG; keep each file under ~500 KB (compress if needed).
- Animated flows can be added as `.gif` and referenced the same way.
