# Tasks

> 현재 진행 중인 작업 및 백로그를 추적하여 AI가 연속 작업을 지원할 수 있도록 함

## 작업 추적 가이드

### 이 문서의 목적

AI가 프로젝트의 현재 맥락을 빠르게 파악하여:
- 이전 작업을 이어서 진행
- 관련 컨텍스트를 고려한 코드 작성
- 우선순위에 맞는 작업 제안

### 작업 상태

| 상태 | 설명 |
|------|------|
| `진행 중` | 현재 작업 중인 항목 |
| `대기` | 다음에 처리할 항목 |
| `검토 필요` | 완료되었으나 확인 필요 |
| `완료` | 완전히 끝난 항목 |
| `보류` | 일시 중단된 항목 |
